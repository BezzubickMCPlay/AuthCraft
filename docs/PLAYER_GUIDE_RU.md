## Начало работы

Добро пожаловать! Это руководство поможет вам защитить ваш аккаунт Minecraft на серверах с AuthCraft.

### Что такое AuthCraft?

AuthCraft — это плагин безопасности, который защищает ваш аккаунт с помощью:
- **Безопасного хранения паролей** — ваш пароль шифруется банковским уровнем защиты
- **Двухфакторной аутентификации** — дополнительная защита для вашего аккаунта
- **Управления сессиями** — оставайтесь в системе без повторного ввода пароля

### Первый раз на сервере?

При первом входе вы увидите сообщение с просьбой зарегистрироваться:

```
Добро пожаловать на сервер!
Пожалуйста, зарегистрируйтесь: /register <пароль> <подтверждение>
```

## Регистрация

### Шаг 1: Придумайте надёжный пароль

Надёжный пароль должен содержать:
- Минимум 8 символов
- Заглавные и строчные буквы
- Цифры и специальные символы
- Не содержать личную информацию

**Хорошие пароли:**
- `МойП@р0ль2024!`
- `Minecraft_Secure_2024`
- `Tr0ub4dor&Horse`

**Плохие пароли:**
- `password`
- `12345678`
- `minecraft`
- Ваш никнейм

### Шаг 2: Зарегистрируйте аккаунт

Напишите в чате:
```
/register МойП@р0ль! МойП@р0ль!
```

Замените `МойП@р0ль!` на ваш выбранный пароль.

### Шаг 3: Готово!

При успешной регистрации вы увидите:
```
Аккаунт успешно зарегистрирован!
Для входа используйте: /login <пароль>
```

### Требования к паролю

Ваш пароль должен соответствовать требованиям:
- Минимум 8 символов
- Максимум 128 символов
- Не должен содержать ваше имя
- Не должен быть в списке популярных паролей
- Достаточная сложность (энтропия)

## Вход в игру

### Обычный вход

После регистрации входите каждый раз при подключении:
```
/login МойП@р0ль!
```

### Восстановление сессии

Если вы уже входили ранее, вы можете быть автоматически авторизованы:
```
Сессия восстановлена! С возвращением!
```

Это происходит, когда:
- Вы входили недавно
- Вы используете тот же IP-адрес
- Ваша сессия не истекла

### Ошибка входа

При неправильном пароле:
```
Неверный пароль! Осталось попыток: 4
```

**Внимание:** После 5 неудачных попыток ваш аккаунт будет временно заблокирован.

## Двухфакторная аутентификация

Двухфакторная аутентификация (2FA) добавляет дополнительный уровень защиты.

### Доступные методы

| Метод | Описание | Уровень защиты |
|-------|----------|----------------|
| TOTP | Приложение Google Authenticator | ⭐⭐⭐⭐⭐ |
| Telegram | Подтверждение через бота | ⭐⭐⭐⭐ |
| VK | Сообщения ВКонтакте | ⭐⭐⭐⭐ |
| Email | Коды на почту | ⭐⭐⭐ |

### Включение TOTP (рекомендуется)

1. **Установите приложение-аутентификатор:**
   - Google Authenticator (Android/iOS)
   - Authy (Android/iOS/ПК)
   - Microsoft Authenticator (Android/iOS)

2. **Включите 2FA:**
   ```
   /2fa enable totp
   ```

3. **Отсканируйте QR-код:**
   - В чате появится кликабельная ссылка
   - Нажмите на неё, чтобы открыть QR-код
   - Отсканируйте приложением-аутентификатором

4. **Подтвердите настройку:**
   - Введите 6-значный код из приложения
   ```
   /2fa verify 123456
   ```

5. **Сохраните резервные коды:**
   ```
   /2fa backup
   ```
   Запишите эти коды и храните их в безопасности!

### Включение Telegram 2FA

1. **Включите Telegram 2FA:**
   ```
   /2fa enable telegram
   ```

2. **Запустите бота:**
   - Вы получите ссылку на бота сервера
   - Откройте ссылку и нажмите "Запустить"

3. **Привяжите аккаунт:**
   - Отправьте боту код подтверждения из игры

4. **Подтверждение:**
   - Вы получите подтверждающее сообщение в Telegram

### Включение VK 2FA

1. **Включите VK 2FA:**
   ```
   /2fa enable vk
   ```

2. **Откройте VK:**
   - Вы получите ссылку на группу сервера
   - Отправьте код подтверждения в группу

3. **Подтверждение:**
   - Вы получите подтверждающее сообщение в VK

### Включение Email 2FA

1. **Включите Email 2FA:**
   ```
   /2fa enable email
   ```

2. **Введите вашу почту:**
   ```
   /2fa email ваша-почта@example.com
   ```

3. **Подтверждение:**
   - Проверьте почту на наличие кода подтверждения
   - Введите код в игре

### Использование 2FA при входе

Когда 2FA включено, после ввода пароля:
```
Требуется 2FA! Введите код из аутентификатора.
Используйте: /2fa verify <код>
```

Введите код из приложения:
```
/2fa verify 123456
```

### Управление 2FA

**Проверить статус:**
```
/2fa status
```

**Отключить метод:**
```
/2fa disable totp
```

**Получить новые резервные коды:**
```
/2fa backup
```

### Резервные коды

Резервные коды используются, когда вы потеряли доступ к методу 2FA.

**Важно:**
- Вы получаете 10 резервных кодов
- Каждый код можно использовать только один раз
- Храните их надёжно (не в скриншотах Minecraft!)
- Создайте новые коды, если они заканчиваются

**Использование резервного кода:**
```
/2fa verify ABCD-1234
```

## Безопасность аккаунта

### Смена пароля

```
/changepassword СтарыйП@роль НовыйП@роль!
```

Требования к новому паролю такие же, как при регистрации.

### Выход из аккаунта

Чтобы выйти (требуется на некоторых серверах перед уходом):
```
/logout
```

### Советы по безопасности

1. **Используйте уникальный пароль** — не используйте пароли от других сервисов

2. **Включите 2FA** — особенно важно для аккаунтов с ценными предметами

3. **Храните резервные коды надёжно** — запишите их, не делайте скриншоты

4. **Не сообщайте пароль никому** — администрация сервера никогда не спросит ваш пароль

5. **Используйте менеджер паролей** — для создания и хранения надёжных паролей

6. **Проверяйте уведомления о входе** — если получили уведомление о входе, который не совершали, немедленно смените пароль

## Решение проблем

### "Неверный пароль", но я уверен, что он правильный

1. Проверьте, выключен ли Caps Lock
2. Убедитесь, что используете правильный аккаунт
3. Свяжитесь с администратором, если заблокированы

### "Аккаунт заблокирован"

Подождите, пока блокировка истечёт (обычно 5-30 минут) или свяжитесь с администратором.

### "Неверный код 2FA"

1. Убедитесь, что время на устройстве синхронизировано
2. Дождитесь нового кода (коды меняются каждые 30 секунд)
3. Используйте резервный код, если есть

### Потерял доступ к 2FA

1. Используйте резервный код
2. Если резервных кодов нет, свяжитесь с администратором с доказательствами владения аккаунтом

### "Сессия истекла"

Просто войдите снова:
```
/login ВашП@роль
```

### "IP изменился, войдите снова"

Это происходит при смене IP. Просто войдите снова.

## Частые вопросы

### В: Нужно ли регистрироваться каждый раз?

**О:** Нет. Регистрация нужна только один раз. После этого просто входите.

### В: Можно ли иметь несколько аккаунтов?

**О:** Большинство серверов ограничивают количество аккаунтов на IP (обычно 3). Проверьте правила сервера.

### В: Что делать, если забыл пароль?

**О:** Свяжитесь с администратором сервера. Он может сбросить ваш пароль.

### В: Безопасен ли мой пароль?

**О:** Да! AuthCraft использует Argon2id — алгоритм шифрования банковского уровня. Даже администраторы сервера не могут увидеть ваш пароль.

### В: Можно ли использовать тот же пароль, что и на других серверах?

**О:** Не рекомендуется. Если один сервер будет взломан, все ваши аккаунты могут быть под угрозой.

### В: Какой метод 2FA лучше?

**О:** TOTP (Google Authenticator) — самый безопасный и не требует интернета для генерации кодов.

### В: Можно ли использовать несколько методов 2FA?

**О:** Да! Вы можете включить все методы для максимальной защиты.

### В: Как долго длится сессия?

**О:** Обычно 7 дней, но это зависит от настроек сервера.

### В: Почему меня выкинуло с сервера?

**О:** Возможные причины:
- Не вошёл вовремя
- Слишком много неудачных попыток
- Перезагрузка сервера
- Проблемы с соединением

## Краткая справка

| Команда | Описание |
|---------|----------|
| `/register <пароль> <пароль>` | Создать аккаунт |
| `/login <пароль>` | Войти |
| `/changepassword <старый> <новый>` | Сменить пароль |
| `/2fa enable <метод>` | Включить 2FA |
| `/2fa disable <метод>` | Отключить 2FA |

| `/2fa verify <код>` | Ввести код 2FA |
| `/2fa backup` | Получить резервные коды |
| `/logout` | Выйти из аккаунта |
